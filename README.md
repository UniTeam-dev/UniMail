# UniMail

Универсальный почтовый клиент для macOS 14+ на SwiftUI: Gmail, Outlook/Exchange, iCloud и любой IMAP в одном окне, быстрое переключение между ящиками и живые анимации.

- План и функциональность: [docs/PLAN.md](docs/PLAN.md)
- Промпт для генерации дизайна: [docs/DESIGN_PROMPT.md](docs/DESIGN_PROMPT.md)

## Сборка

```bash
./rebuild.command          # собрать release, подписать и запустить
./scripts/build.sh debug   # только собрать debug-версию в dist/UniMail.app
```

Для подписи используется сертификат «NotchApp Dev», если он есть (другой можно задать через `UNIMAIL_CERT=...`). Если сертификата нет, приложение подписывается ad-hoc.

## Состояние (этап 0)

Приложение работает на трёх демо-аккаунтах. Уже готово:

- панель аккаунтов с анимированным выбором, счётчиками и индикатором синхронизации; единый ящик и скрытие ящиков из него;
- папки, категории входящих (Люди / Уведомления / Рассылки), поиск с токенами `from:`, `subject:`, `has:attachment`, `is:unread`;
- треды, чтение HTML в изолированном WKWebView: без JS, удалённые картинки заблокированы, трекинг-пиксели вырезаются;
- контекстные плашки: приглашение в календарь, «Скопировать код»;
- архив, удаление, флаг, отложить, спам — оптимистично, с окном «Отменить»;
- написание письма: токены адресов, выбор отправителя, вложения, «отправить позже», «каждому отдельно», предупреждение о забытом вложении, «Отменить отправку»;
- быстрый ответ под тредом, командная палитра ⌘K, свайпы строк, горячие клавиши (J/K/E/H/R/S/U/#, ⌘0…⌘9).

Настоящие IMAP, Gmail и Graph подключаются на этапах 2–4, код провайдеров пишется под протокол `MailProvider`.

## Структура

```
Sources/UniMail/
  App/        точка входа, меню и шорткаты
  Core/       модели, провайдеры, MailStore, Keychain, санитайзер HTML
  UI/         SwiftUI-экраны и дизайн-система (Theme.swift — цвета и анимации)
```
