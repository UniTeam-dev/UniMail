# UniMail

Универсальный почтовый клиент для macOS 14+ на SwiftUI: Gmail, Outlook/Exchange, iCloud и любой IMAP в одном окне, быстрое переключение между ящиками и живые анимации.

- План и функциональность: [docs/PLAN.md](docs/PLAN.md)
- Промпт для генерации дизайна: [docs/DESIGN_PROMPT.md](docs/DESIGN_PROMPT.md)

## Сборка

```bash
./rebuild.command          # собрать release, подписать и запустить
./scripts/build.sh debug   # только собрать debug-версию в dist/UniMail.app
```

Для подписи используется сертификат «NotchApp Dev», если он есть (другой можно задать через `UNIMAIL_CERT=...`). Если сертификата нет, приложение подписывается ad-hoc.

## Состояние

Сделаны все этапы плана, кроме нотаризации и автообновлений (см. [docs/PLAN.md](docs/PLAN.md)). Код ещё не собирался на Mac: первая сборка через `rebuild.command` покажет ошибки компиляции интерфейса, если они есть. Ядро (IMAP, SMTP, MIME, база, провайдер, MailStore) проверено на Linux.

- **Ящики:** Gmail, iCloud, Яндекс, Mail.ru, корпоративный Exchange и любой IMAP по паролю приложения. Мастер сначала проверяет вход по IMAP и SMTP. Пароли хранятся в Связке ключей. Демо-ящики остаются, пока вы их не удалите.
- **Синхронизация:** входящие, отправленные, черновики, архив, спам и корзина за последние 30 дней; новые письма приходят сразу (IDLE); тела писем скачиваются при открытии; всё хранится в `~/Library/Application Support/UniMail/mail.sqlite`.
- **Офлайн:** действия без связи записываются в журнал и повторяются; письмо без связи ждёт в «Запланированных».
- **Письма:** треды, отложить, «напомнить, если не ответят», правила, категории с обучением («Категория отправителя» в меню имени), отписка в один клик, приглашения с ответом организатору и записью в Календарь, поиск по телам писем и на сервере, экспорт в PDF, печать, .eml.
- **Написание:** форматирование текста (жирный, курсив, подчёркивание, списки, ссылки, цитаты), вложения, шаблоны, подписи (несколько на ящик, своя для новых писем и для ответов — подставляются сами, меняются кнопкой «Подпись» в окне письма), «Отменить отправку», «Отправить позже», «каждому отдельно».
- **Свайпы:** мышью с нажатой кнопкой и двумя пальцами по трекпаду: вправо — архив, влево — отложить до завтра.
- **Система:** уведомления с действиями, бейдж в Dock, строка меню, запуск при входе, AI-сводка и черновик ответа по вашему ключу Anthropic.

## Структура

```
Sources/UniMail/
  App/        точка входа, меню и шорткаты
  Core/       модели, провайдеры, MailStore, Keychain, санитайзер HTML
  UI/         SwiftUI-экраны и дизайн-система (Theme.swift — цвета и анимации)
```
