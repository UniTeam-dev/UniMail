# UniMail

Универсальный почтовый клиент для macOS 14+ на SwiftUI: Gmail, Outlook/Exchange, iCloud и любой IMAP в одном окне, быстрое переключение между ящиками и живые анимации.

- План и функциональность: [docs/PLAN.md](docs/PLAN.md)
- Промпт для генерации дизайна: [docs/DESIGN_PROMPT.md](docs/DESIGN_PROMPT.md)

## Сборка

```bash
./rebuild.command          # собрать release, подписать и запустить
./scripts/build.sh debug   # только собрать debug-версию в dist/UniMail.app
```

Для подписи используется сертификат «NotchApp Dev», если он есть (другой можно задать через `UNIMAIL_CERT=...`). Если сертификата нет, приложение подписывается ad-hoc.

## Состояние (этап 0 + дизайн)

Интерфейс собран по макету из Claude Design (`design/`): токены обеих тем, типографика, три плотности списка, анимации по раскадровке, иконка приложения. Работает на демо-ящиках «Работа», «Личное» и «Студия».

- Окно без системного заголовка: панель аккаунтов 66 pt, папки 210, список 390, чтение; при ширине меньше 1150 pt колонки сужаются.
- Панель аккаунтов: подложка и «таблетка» переезжают пружиной, красные бейджи, кольцо синхронизации, значок ошибки.
- Список: категории с бегунком, строка с меткой аккаунта, свайпы (архив / отложить), пустые состояния, баннер ошибки синхронизации.
- Чтение: карточки писем, плашка приватности, приглашение с ответами, код подтверждения с копированием, быстрый ответ, меню «Отложить».
- Переключатель «Почта / Расписание»: лента дня, недельная повестка, мини-календарь, слои.
- Командная палитра ⌘K, тост «Отменить», окно письма с отправкой по расписанию, мастер добавления ящика, настройки.
- Клавиши: ⌘1 — все ящики, ⌘2…9 — ящики, J/K, E, H, R, S, U, #, ⌘K, ⇧⌘2 — расписание.

Настоящий IMAP подключается на этапе 2, код провайдеров пишется под протокол `MailProvider`.

## Структура

```
Sources/UniMail/
  App/        точка входа, меню и шорткаты
  Core/       модели, провайдеры, MailStore, Keychain, санитайзер HTML
  UI/         SwiftUI-экраны и дизайн-система (Theme.swift — цвета и анимации)
```
