# UniMail — универсальный почтовый клиент для macOS

Рабочее название — **UniMail**. Ориентир — Orvia Mail: нативное приложение, единый ящик, данные хранятся на Mac, работает офлайн, AI по желанию.

## 1. Принципы

1. **Нативность.** SwiftUI + AppKit, системные меню, шорткаты, уведомления. Никаких веб-обёрток. Веб-движок (WKWebView) используется только для показа HTML-писем.
2. **Скорость.** Список писем открывается мгновенно из локальной базы, сеть синхронизирует в фоне. Переключение аккаунта занимает меньше 100 мс.
3. **Локальность и приватность.** Письма лежат в SQLite на Mac, пароли и токены хранятся в Keychain. Удалённые картинки и трекинг-пиксели по умолчанию заблокированы.
4. **Честный офлайн.** Все действия (архив, перемещение, отправка) идут через журнал операций. Письмо, отправку которого сервер не подтвердил, никогда не показывается как отправленное.
5. **Живой интерфейс.** Анимации со смыслом: пружинные переходы, matched geometry между списком и письмом, свайпы, микро-отклик на действия. Везде соблюдается настройка «Уменьшить движение».

## 2. Функциональность

### 2.1 Аккаунты и провайдеры
| Провайдер | Протокол | Вход |
|---|---|---|
| Любой IMAP/SMTP (Яндекс, Mail.ru, корпоративные) | IMAP4rev1/rev2 + IDLE, SMTP (465/587 STARTTLS) | пароль / пароль приложения, автопоиск настроек |
| Корпоративный Outlook (Exchange on-prem) | IMAP/SMTP | доменный логин и пароль |
| iCloud | IMAP/SMTP (пресет) | пароль приложения |
| Gmail | IMAP/SMTP + расширения Gmail (X-GM-LABELS, X-GM-THRID, X-GM-RAW) | пароль приложения (нужна двухэтапная аутентификация) |
| *Позже, по необходимости:* Microsoft 365 / Outlook.com | IMAP/SMTP с XOAUTH2 или Graph | OAuth 2.0 PKCE, регистрация в Microsoft Entra |
| *Позже, для публичного релиза:* Gmail | Gmail REST API | OAuth, Google Cloud + верификация |

**Решение:** все ящики подключаются по IMAP/SMTP с паролями. Консоли Google и Azure не нужны. OAuth понадобится, только если появится ящик в облачном Microsoft 365 / Outlook.com: там вход по паролю для IMAP отключён.

- Автонастройка по домену: встроенные пресеты, Mozilla ISPDB (autoconfig), SRV-записи.
- Несколько адресов отправителя (алиасы; для Gmail — адреса из «Send mail as», отправка через SMTP Gmail), свой цвет и аватар у каждого аккаунта.
- Для каждого аккаунта — подписи, отображаемое имя и настройки уведомлений.

### 2.2 Быстрое переключение между почтами
- **Панель аккаунтов** слева: цветные аватары, счётчики непрочитанных, перетаскиванием меняется порядок.
- **Единый ящик** («Все входящие») и единые папки «Отправленные», «Черновики», «Отмеченные».
- ⌘0 открывает единый ящик, ⌘1…⌘9 — конкретный аккаунт, ⌃Tab — следующий аккаунт.
- **Командная палитра ⌘K**: переход к аккаунту, папке или письму, запуск любого действия.
- В режиме единого ящика у каждого письма есть цветная метка аккаунта, а фильтр-чипсы позволяют скрывать отдельные аккаунты.

### 2.3 Работа с письмами
- Треды (группировка по References / In-Reply-To, для Gmail — X-GM-THRID), сворачивание прочитанных.
- Прочитано/непрочитано, флаг, архив, удаление, перемещение, метки (Gmail) и категории (Outlook), спам.
- Массовые действия, выделение ⇧/⌘, «выбрать все похожие от отправителя».
- Свайпы на трекпаде: вправо — архив, влево — отложить; действия настраиваются.
- **Отложить (Snooze)**: письмо возвращается во «Входящие» в заданное время.
- **Напомнить, если не ответили (Follow-up)**.
- **Отменить отправку** (5–30 с), **отправить позже**, **отправить каждому отдельно** (персональная рассылка).
- Шаблоны и быстрые ответы.
- Правила (фильтры) и умные папки (сохранённые поиски).
- Категории входящих: «Люди», «Уведомления», «Рассылки». Приложение учится на исправлениях пользователя.
- «Отписаться» в один клик (List-Unsubscribe / RFC 8058).
- Контекстные кнопки: у приглашения — «Добавить в календарь», у задачи — «В Напоминания», у кода входа — «Скопировать код».
- Экспорт письма или треда в PDF, сохранение .eml, печать.

### 2.4 Чтение
- Безопасный рендеринг HTML: санитизация, блокировка удалённого контента (разрешение по отправителю), вырезание трекинг-пикселей, CSP.
- Адаптация писем к тёмной теме.
- Предпросмотр вложений через Quick Look, сохранение и перетаскивание в Finder.
- Сворачивание цитат и подписей.

### 2.5 Написание
- Отдельное окно или встроенный ответ. Rich text (жирный, списки, ссылки, картинки inline) или plain text.
- Автодополнение адресов (локальная история, Контакты macOS; в них можно подключить Google и Exchange на уровне системы).
- Вложения перетаскиванием, предупреждение «вы упомянули вложение, но не приложили его».
- Автосохранение черновиков локально и на сервер.
- Выбор отправителя (аккаунт / алиас) прямо в поле «От».

### 2.6 Расписание (календарь)
- Вкладка «Расписание»: повестка на сегодня и неделю из системного Календаря (EventKit). Google, Exchange и iCloud подключаются в Календаре macOS один раз, без OAuth в нашем приложении.
- Разбор приглашений .ics в письмах, ответы Принять / Под вопросом / Отклонить (iTIP).
- Создание встречи из письма: участники подставляются из треда.
- Отправка по расписанию — локальный планировщик с login item-хелпером, который отправит письмо, даже если окно закрыто.

### 2.7 Поиск
- Мгновенный локальный полнотекстовый поиск (SQLite FTS5) с токенами `from:`, `to:`, `subject:`, `has:attachment`, `before:`/`after:`.
- Поиск на сервере по старым письмам, которые не скачаны (IMAP SEARCH, для Gmail — X-GM-RAW с синтаксисом веб-поиска).

### 2.8 Система
- Уведомления с действиями (Архив, Ответить, Прочитано), бейдж на иконке в Dock.
- Иконка в строке меню с быстрым просмотром непрочитанного.
- Настройки: аккаунты, внешний вид (акцентный цвет, плотность списка, шрифт), поведение, шорткаты.
- Импорт и экспорт настроек, синхронизация настроек через iCloud (по желанию).

### 2.9 AI (по желанию, выключен по умолчанию)
- Сводка треда, черновик ответа, «переписать вежливее / короче».
- Работает на ключе пользователя (Anthropic / OpenAI-совместимый API) или на локальной модели. Перед отправкой персональные данные маскируются.

## 3. Архитектура

```
UniMail.app
├── App/            точка входа, окна, меню, команды, AppDelegate
├── UI/             SwiftUI-экраны + дизайн-система (цвета, типографика, анимации)
├── Core/
│   ├── Models/     Account, Mailbox, Message, Thread, Address, Attachment, Draft
│   ├── Providers/  протокол MailProvider + IMAP (с расширениями Gmail/Exchange), Demo
│   ├── Sync/       SyncEngine, ActionQueue (журнал офлайн-операций), Scheduler
│   ├── Store/      MailStore (сейчас в памяти → GRDB/SQLite + FTS5)
│   ├── Auth/       Keychain (OAuth — только если понадобится этап 4)
│   └── Render/     санитайзер HTML, блокировка трекеров
└── Helper/         login item для отправки по расписанию (этап 6)
```

**Ключевой контракт** — `MailProvider`: список папок, инкрементальная синхронизация (курсор: UIDVALIDITY + HIGHESTMODSEQ, CONDSTORE/QRESYNC), загрузка тела, действия над письмами, отправка. UI знает только `MailStore` и никогда не обращается к провайдерам напрямую.

**Поток данных:** провайдер → SyncEngine → MailStore (SQLite) → `@Observable` view-модели → SwiftUI. Действия пользователя: UI → ActionQueue (сразу применяется оптимистично к Store) → провайдер → подтверждение или откат.

**Зависимости:** `swift-nio-imap` (Apple, IMAP-парсер), `GRDB.swift` (SQLite + FTS5), `SwiftSoup` (санитизация HTML), `Sparkle` (обновления). SMTP — свой клиент поверх SwiftNIO + NIOSSL.

**Сборка:** SwiftPM + `scripts/build.sh` собирает `.app`, подписывает и кладёт в `dist/` (так же, как в NotchApp). Минимальная версия — macOS 14 Sonoma.

## 5. Что нужно от тебя
- **Gmail:** включить двухэтапную аутентификацию, создать пароль приложения (myaccount.google.com → Безопасность → Пароли приложений) и включить IMAP в настройках Gmail.
- **iCloud:** пароль приложения на account.apple.com.
- **Яндекс / Mail.ru:** пароль приложения в настройках безопасности и разрешение IMAP в настройках почты.
- **Корпоративный Outlook:** адрес IMAP/SMTP-сервера (его видно в настройках Outlook или у админов) и включённый для ящика IMAP. Если сервер `outlook.office365.com`, это облачный Microsoft 365 — там понадобится этап 4.

## 6. Риски
- **Отправка по расписанию для IMAP/Gmail** работает, только пока Mac включён. Это решается login item-хелпером; предупредим пользователя в UI.
- **Пароль приложения Gmail** сбрасывается при смене пароля Google — клиент должен понятно попросить новый.
- **Корпоративный Exchange:** админы могут отключить IMAP; тогда нужен EWS-адаптер (отдельная задача).
- **Объём почты.** Сначала синхронизируются заголовки последних N дней, тела писем подгружаются лениво, старое ищется на сервере.
